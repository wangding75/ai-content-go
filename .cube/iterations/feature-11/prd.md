# Iteration 11 PRD：平台适配器与浏览器插件

## 1. 功能概述

本次迭代建立平台适配器、浏览器插件协作和 n8n 外围自动化闭环，让运营人员可以在管理台配置发布平台规则、管理插件客户端、通过插件辅助人工发布、回填发布结果与平台采集数据，并在管理台查看采集日志和外部自动化回调处理结果。

本迭代包含以下功能点：

- 平台 Adapter 配置管理：维护平台标识、发布模式、字段映射、填充规则、采集规则、凭证引用、启停状态和版本信息。
- 插件客户端管理与认证：支持 Chrome 插件客户端注册、禁用 / 启用、密钥轮换、短期认证、权限范围和活跃状态管理。
- 插件发布任务协作：插件从既有发布队列领取任务、锁定任务、获取填充载荷、回填填充 / 已发布 / 失败事件。
- 平台采集日志与指标确认：接收插件或外围自动化提交的平台采集结果，支持列表、详情、失败排查和人工确认写入指标。
- n8n 外围回调：接收通知、外部同步、告警、第三方采集等外围事件，记录回调日志并防止 n8n 越界承载核心流程。
- 前端管理台页面：实现平台 Adapter、插件客户端、外部自动化 / n8n、采集日志页面，并接入现有导航和原型视觉交互。

## 2. Functional Requirements

### 平台 Adapter 配置管理

#### FR-001（P0）新增平台 Adapter 配置

用户可以在“平台 Adapter”页面新增平台配置。

- 输入：平台编码、展示名称、发布模式、目标类型、字段映射、填充规则、采集规则、凭证引用和启用状态。
- 输出：新建成功后返回 Adapter 配置 ID、当前版本和创建结果，并在列表中可见。
- 异常处理：平台编码缺失、发布模式不合法、字段映射格式错误或凭证引用不可用时，页面展示统一错误码、错误信息和 request_id。

#### FR-002（P0）查看和筛选平台 Adapter 配置列表

用户可以查看 Adapter 配置列表，并按平台、发布模式、启用状态分页筛选和排序。

- 输入：平台、发布模式、启用状态、分页和排序条件。
- 输出：Adapter 配置列表、版本、状态摘要和分页信息。
- 异常处理：查询失败时展示错误态；无数据时展示空态和新增入口。

#### FR-003（P0）查看平台 Adapter 配置详情

用户可以打开 Adapter 详情，查看平台规则摘要、字段映射、填充规则、采集规则、版本和启用状态。

- 输入：Adapter 配置 ID。
- 输出：配置详情、规则摘要、版本信息和最近更新时间。
- 异常处理：配置不存在时展示 NOT_FOUND；无权限时展示 FORBIDDEN。

#### FR-004（P0）编辑、启用或停用平台 Adapter 配置

用户可以编辑 Adapter 配置，并启用或停用平台能力。

- 输入：展示名称、字段映射、填充规则、采集规则、启用状态和变更原因。
- 输出：更新后的版本号、状态和操作日志 ID。
- 异常处理：规则格式错误、版本冲突、无权限或停用后仍有不可处理任务时，返回明确错误；页面保留用户输入并展示失败原因。

### 插件客户端管理与认证

#### FR-005（P0）注册插件客户端

管理员可以在“插件客户端”页面注册 Chrome 插件客户端。

- 输入：客户端名称、客户端类型、版本号和权限范围。
- 输出：插件客户端 ID，以及仅本次可见的一次性 api_key。
- 异常处理：名称重复、版本不兼容或权限范围不合法时返回统一错误；api_key 只允许创建成功时明文展示，刷新后不可再次查看。

#### FR-006（P0）查看和筛选插件客户端列表

用户可以查看插件客户端列表，了解客户端状态、版本、权限范围、最后活跃时间和密钥状态。

- 输入：状态、客户端类型、分页条件。
- 输出：插件客户端列表、脱敏密钥信息、最后活跃时间和分页信息。
- 异常处理：无数据时展示空态；接口失败时展示错误码、错误信息和 request_id。

#### FR-007（P0）启用、禁用插件客户端和调整权限范围

管理员可以启用或禁用插件客户端，并调整其权限范围。

- 输入：客户端 ID、目标状态、权限范围和变更原因。
- 输出：更新后的客户端状态和操作日志 ID。
- 异常处理：客户端不存在、状态流转不合法、权限范围越界时返回明确错误；禁用后新认证必须失败。

#### FR-008（P0）轮换插件客户端密钥

管理员可以为插件客户端重新生成密钥。

- 输入：客户端 ID 和轮换原因。
- 输出：新的 api_key_once 和操作日志 ID；旧密钥立即失效。
- 异常处理：客户端不存在、已禁用或无权限时返回错误；新密钥只允许轮换成功时明文展示一次。

#### FR-009（P0）插件短期认证

Chrome 插件可以使用 api_key 换取短期 access_token。

- 输入：api_key 和客户端版本。
- 输出：access_token、过期时间和权限范围。
- 异常处理：api_key 无效、客户端被禁用、版本不兼容或权限不足时认证失败并记录审计；不得泄露密钥校验细节。

### 插件发布任务协作

#### FR-010（P0）插件拉取可处理发布任务

已认证插件可以按项目、平台、状态分页拉取自己权限范围内的待处理发布任务。

- 输入：项目 ID、平台、状态、分页条件和插件访问令牌。
- 输出：可处理发布任务列表、分页信息、发布目标摘要和任务状态。
- 异常处理：Token 过期、权限不足、Adapter 已禁用或没有可处理任务时返回对应状态；无任务时展示空结果而不是错误。

#### FR-011（P0）插件领取并锁定发布任务

插件可以领取发布任务，避免多个插件同时填充同一任务。

- 输入：发布任务 ID、锁定时长和插件访问令牌。
- 输出：lock_id、locked_until、填充载荷、payload_hash、content_version_id、Adapter 配置 ID 和 Adapter 版本。
- 异常处理：任务已被其他插件锁定、任务状态不可领取、锁已过期或 Adapter 不可用时返回冲突或状态错误；锁定超时后允许释放或重新领取。

#### FR-012（P0）插件回填“已填充”事件

插件完成页面填充后，可以回填已填充事件，但该事件不等同于发布完成。

- 输入：发布任务 ID、lock_id、payload_hash 和备注。
- 输出：事件 ID 和当前任务状态。
- 异常处理：锁无效、payload_hash 不匹配、任务状态不允许填充时返回明确错误，并记录失败摘要。

#### FR-013（P0）插件回填“已发布”结果

用户在平台完成人工确认发布后，插件可以回填外部链接和发布时间。

- 输入：发布任务 ID、lock_id、external_url、published_at、payload_hash、备注和 Idempotency-Key。
- 输出：发布任务 ID、更新后的发布状态和操作日志 ID。
- 异常处理：重复提交同一 Idempotency-Key 必须返回相同结果；请求体不一致返回 IDEMPOTENCY_CONFLICT；锁无效、状态非法或外部链接格式错误时返回明确错误。

#### FR-014（P0）插件回填发布失败

插件可以回填平台发布失败结果，帮助用户排查和重试。

- 输入：发布任务 ID、lock_id、失败原因、是否可重试、平台错误摘要和 Idempotency-Key。
- 输出：发布任务 ID、失败状态和操作日志 ID。
- 异常处理：重复提交不得重复推进状态或重复写日志；缺少失败原因时返回校验错误。

### 平台采集日志与指标确认

#### FR-015（P0）提交平台采集日志

插件或外围自动化可以提交平台表现数据采集日志。

- 输入：项目 ID、平台、目标账号、发布任务 ID、内容项 ID、外部 URL、原始 payload、解析指标、采集时间。
- 输出：采集日志 ID 和解析状态。
- 异常处理：缺少项目或平台、原始 payload 不合法、解析指标格式错误时返回校验错误；采集失败也必须保存失败摘要，便于后续排查。

#### FR-016（P0）查看和筛选平台采集日志列表

用户可以在“采集日志”页面查看采集记录，并按项目、平台、状态分页筛选和排序。

- 输入：项目 ID、平台、状态、分页和排序条件。
- 输出：采集日志列表、采集时间、解析状态、关联发布任务、错误摘要和分页信息。
- 异常处理：无数据时展示空态；查询失败时展示统一错误结构。

#### FR-017（P0）查看采集日志详情

用户可以查看单条采集日志的原始数据、解析指标、关联内容、关联发布任务和错误信息。

- 输入：采集日志 ID。
- 输出：采集详情、raw_payload、parsed_metrics、关联对象和错误摘要。
- 异常处理：日志不存在或无权限时展示对应错误；原始数据较大时页面仍需可阅读和可折叠展示。

#### FR-018（P0）人工确认采集指标写入 MetricRecord

用户可以人工确认采集结果并写入指标中心。

- 输入：采集日志 ID、待写入指标记录、备注。
- 输出：生成的指标记录 ID 列表和操作日志 ID。
- 异常处理：指标模板不匹配、重复写入、日志状态不可确认或无权限时返回明确错误；默认不得在无人工确认或显式配置时直接污染指标中心。

### n8n 外围回调

#### FR-019（P0）接收 n8n 外围回调

系统可以接收 n8n 或外部自动化 Provider 的外围事件回调。

- 输入：bindingId、事件类型、payload、幂等键或稳定事件 ID。
- 输出：accepted 状态和 callback_log_id。
- 异常处理：未知事件类型、payload schema 不合法、绑定不存在或幂等冲突时返回统一错误；失败必须保留错误摘要和 request_id。

#### FR-020（P0）限制 n8n 回调边界

n8n 回调只能处理通知、Webhook、外部同步、告警和轻量采集事件。

- 输入：外围事件回调。
- 输出：回调日志和接受 / 拒绝结果。
- 异常处理：试图创建核心 WorkflowRun、推进 Agent 编排、绕过发布状态机或直接修改内容正文的回调必须被拒绝并记录审计。

### 前端页面与原型交互

#### FR-021（P0）实现平台 Adapter 管理页面

用户可以从导航进入 `/platform-adapters` 页面，完成 Adapter 列表查看、新增、详情、编辑、启停和反馈交互。

- 输入：用户筛选条件、表单字段和状态操作。
- 输出：页面展示配置列表、详情、成功 Toast、错误态和空态。
- 异常处理：接口失败时展示错误码、错误信息和 request_id；页面刷新后不出现 404。

#### FR-022（P0）实现插件客户端页面

用户可以从导航进入 `/plugin-clients` 页面，完成插件注册、客户端列表查看、禁用 / 启用、密钥轮换和一次性密钥展示。

- 输入：客户端注册字段、筛选条件和状态操作。
- 输出：客户端列表、一次性 api_key 弹窗、状态标签和操作反馈。
- 异常处理：api_key 只展示一次；错误态必须样式化展示统一错误结构。

#### FR-023（P0）实现外部自动化 / n8n 页面

用户可以从导航进入 `/external-automation/n8n` 页面，查看 Provider、绑定、回调用途和回调日志入口。

- 输入：Provider / 绑定筛选条件、测试回调或状态操作。
- 输出：外部自动化列表、边界说明、回调状态和操作反馈。
- 异常处理：测试失败、回调错误或无绑定时展示明确反馈和 request_id。

#### FR-024（P0）实现平台采集日志页面

用户可以从导航进入 `/platform-collect-logs` 页面，查看采集日志列表、详情、失败筛选和人工确认入口。

- 输入：筛选条件、分页条件、采集日志 ID、确认指标记录。
- 输出：采集列表、详情弹窗 / 页面、错误摘要、确认结果和指标记录 ID。
- 异常处理：采集失败记录必须可筛选；确认失败需展示错误码、错误信息和 request_id。

#### FR-025（P0）按原型实现管理台视觉和可点击交互

本迭代新增页面必须基于 `docs/requirements/ai-content-factory-clickable-prototype.html` 中的平台 Adapter、外部自动化 / n8n 等原型区域实现，并补齐插件客户端和采集日志页面的同风格管理台交互。

- 输入：导航点击、筛选、分页、表单、弹窗、状态操作和详情跳转。
- 输出：统一 AppLayout、导航高亮、卡片 / 表格 / 表单 / 弹窗 / 状态标签、Toast 或 Alert 反馈。
- 异常处理：不得出现裸 HTML、CSS 未加载、按钮无反馈、只能手输 URL 访问、刷新 404 或错误态不展示 request_id。

## 3. Non-Functional Requirements

### NFR-001（P0）安全与凭证保护

- 插件 api_key 只能创建或轮换成功时返回一次明文，服务端不得保存明文。
- 插件认证使用短期 access_token，并校验客户端状态、版本兼容性和权限范围。
- Adapter 凭证只能保存 credential_ref，不保存平台账号密码或敏感凭证明文。
- 所有插件任务、采集和 n8n 回调接口必须执行认证、授权和输入校验。

### NFR-002（P0）幂等与一致性

- 插件发布结果回填、发布失败回填和 n8n 回调必须支持 Idempotency-Key 或稳定事件 ID。
- 重复提交不得重复推进状态或重复写操作日志。
- 发布任务领取必须有锁定机制，避免多个插件重复填充同一发布任务。

### NFR-003（P0）审计与可追踪

- Adapter 配置变更、插件注册 / 禁用 / 轮换、插件认证失败、任务领取、发布回填、采集确认和 n8n 回调处理均需记录操作日志或领域日志。
- 平台采集结果写入 MetricRecord 时必须保留 platform_collect_log 来源，避免重复采集造成指标污染。

### NFR-004（P0）API 契约一致性

- 所有接口必须使用 `/api/v1` 前缀、统一响应结构、统一错误结构和 request_id。
- 列表接口必须支持分页；涉及列表筛选的页面必须支持筛选、分页和错误态。
- 所有接口必须进入 OpenAPI，并具备 Go request / response DTO 和入参校验。

### NFR-005（P1）前端兼容性与可验收性

- 新增页面必须接入现有导航体系，并支持刷新后直接访问。
- 页面必须具备加载态、空态、成功态、错误态。
- E2E 或集成测试需覆盖从导航入口进入页面、主要按钮点击、接口成功渲染和接口失败渲染。

### NFR-006（P1）平台扩展性

- Adapter 配置必须版本化，并至少支持一个示例平台用于联调。
- 字段映射、填充规则和采集规则应支持后续 Article Pack、Social Post Pack 的平台差异。

## 4. 验收标准

### 平台 Adapter 配置管理

- AC-001：用户可以在 `/platform-adapters` 从导航进入 Adapter 管理页面，页面按管理台样式渲染且刷新不 404。
- AC-002：新增 Adapter 配置成功后，页面显示成功反馈，并能在列表中看到新配置和版本信息。
- AC-003：Adapter 列表支持平台、发布模式、启用状态、分页和排序筛选。
- AC-004：Adapter 详情展示字段映射、填充规则、采集规则、凭证引用、启用状态和版本。
- AC-005：编辑或启停 Adapter 后返回新版本和 operation_log_id；状态变更可追踪。
- AC-006：Adapter 表单校验失败时，页面展示错误码、错误信息和 request_id。

### 插件客户端管理与认证

- AC-007：管理员可以注册插件客户端，并且 api_key 只在创建成功弹窗中展示一次。
- AC-008：插件客户端列表展示客户端名称、类型、版本、状态、scope、最后活跃时间和脱敏密钥信息。
- AC-009：管理员可以禁用 / 启用插件客户端并调整 scope，操作成功后返回 operation_log_id。
- AC-010：管理员可以轮换插件密钥，旧密钥立即失效，新密钥只展示一次。
- AC-011：插件使用有效 api_key 可以换取短期 access_token；禁用、过期、版本不兼容或 scope 不足时认证失败。
- AC-012：插件认证失败不会泄露密钥校验细节，并记录审计信息。

### 插件发布任务协作

- AC-013：插件拉取发布任务时，只返回当前插件 scope 内且允许插件处理的 publish_job。
- AC-014：插件领取任务后返回 lock_id、locked_until、payload、payload_hash、content_version_id 和 Adapter 版本。
- AC-015：同一 publish_job 被有效锁定期间，其他插件不能重复领取。
- AC-016：插件回填 filled 事件后，任务记录填充事件，但不会直接视为发布完成。
- AC-017：插件回填 published 结果时校验 lock_id、payload_hash、external_url 和状态流转，成功后更新 publish_job 并写操作日志。
- AC-018：插件回填 failed 结果时记录 reason、retryable 和 platform_error，用户可据此排查或重试。
- AC-019：相同 Idempotency-Key 重复提交 published / failed 回填返回相同结果，不重复写日志；请求体不一致返回 IDEMPOTENCY_CONFLICT。

### 平台采集日志与指标确认

- AC-020：插件或外围自动化可以提交 platform_collect_log，记录 raw_payload、parsed_metrics、采集来源、外部 URL 和关联对象。
- AC-021：采集日志列表支持项目、平台、状态、分页和排序筛选。
- AC-022：采集日志详情展示原始 payload、解析指标、关联发布任务 / 内容项、错误摘要和采集时间。
- AC-023：采集失败、解析失败和模板缺失记录可以被筛选出来。
- AC-024：用户可以人工确认采集结果写入 MetricRecord，成功后返回 metric_record_ids 和 operation_log_id。
- AC-025：默认情况下，采集结果不会绕过人工确认直接写入 MetricRecord；自动回填必须显式配置且保留来源。

### n8n 外围回调

- AC-026：n8n 回调成功后返回 accepted 和 callback_log_id，并保存回调日志。
- AC-027：未知事件类型、schema 校验失败或绑定不存在时返回统一错误结构。
- AC-028：n8n 回调幂等重复提交不会重复处理；请求体冲突时返回幂等冲突错误。
- AC-029：n8n 回调不能创建核心 WorkflowRun、推进 Agent 编排、绕过发布状态机或直接修改内容正文。

### 前端页面与原型交互

- AC-030：新增页面接入全局导航，不允许核心页面只能手输 URL 访问。
- AC-031：平台 Adapter、插件客户端、外部自动化 / n8n、采集日志页面均具备加载态、空态、成功态和错误态。
- AC-032：新增页面使用统一 AppLayout，CSS 生效，卡片、表格、表单、按钮、弹窗和状态标签不是裸 HTML。
- AC-033：导航、筛选、分页、表单提交、弹窗开关、详情跳转、状态操作均可点击并有反馈。
- AC-034：接口失败时，页面展示 error.code、error.message 和 request_id。
- AC-035：E2E 或集成测试覆盖从导航入口进入页面、主要按钮点击、接口成功渲染和接口失败渲染。

## 5. Out of Scope

- 不实现完全无人值守的平台自动发布；插件只做辅助填充、人工确认和结果回填。
- 不绕过已有发布队列和 publish_job 状态机新增一套插件发布主状态机。
- 不让 n8n 承载核心 Workflow Engine、Agent 编排、核心发布状态机或内容正文修改。
- 不保存平台账号密码、插件 api_key 明文或其他敏感凭证明文。
- 不承诺覆盖所有真实平台 DOM 自动化、反爬、登录态维护和复杂采集适配。
- 不默认把采集结果自动写入 MetricRecord；自动写入必须显式配置并可追踪来源。
- 不新增 Novel / Book / Chapter 等小说专属核心资源命名。
- 不开发 Iteration 12 / 13 的 Article Pack 或 Social Post Pack 专属业务能力，只保留 Adapter 扩展兼容性。
- 不实现超出平台 Adapter、插件客户端、n8n 外围自动化、平台采集日志页面范围的其他管理台页面。

## 6. 依赖说明

- 依赖 Iteration 1 的 ContentProject / ContentType 作为项目和内容类型边界。
- 依赖 Iteration 2.1 的外部自动化 Provider / Binding / 调用日志概念，n8n 能力需与其兼容。
- 依赖 Iteration 5 的内容审核与 content_version，插件填充载荷必须绑定可发布版本。
- 依赖 Iteration 7 的 publish_target、publish_job、publish_log 和发布状态机。
- 依赖 Iteration 8 的 metric_template 和 metric_record，采集日志人工确认后才能写入指标中心。
- 与 Iteration 10 的 Portfolio 不直接耦合，但发布和采集状态应可供后续健康汇总读取。
- 前端视觉与交互依赖 `docs/requirements/ai-content-factory-clickable-prototype.html` 的管理台原型风格。
